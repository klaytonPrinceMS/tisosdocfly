# Manual do usuário comum

## Entrar

1. Acesse `/login`.
2. Informe usuário e senha.
3. No primeiro acesso, o sistema pode pedir troca de senha e confirmação de
   dados de contato.

## Home

A home mostra apenas os módulos liberados para a sua conta. Um módulo
desligado aparece como aviso e não abre até o administrador liberar.

## Meu perfil

No menu, abra **Meu perfil** para:

- alterar e-mail e telefone;
- trocar a própria senha;
- ativar o segundo fator (TOTP), se disponível;
- alternar o tema claro/escuro.

## Problemas comuns

| Sintoma | Causa provável |
|---|---|
| Volta para o login sozinho | Sessão encerrada pelo administrador ou timeout |
| "Acesso negado" | Falta papel no módulo; peça liberação |
| "Módulo desligado" | O administrador ainda não ativou o módulo |
